# Интерактивное пособие 81-717/714

Интерактивные схемы приборов электропоездов метро 81-717/714: краны машиниста 334 и 013, редуктор 348, воздухораспределитель 337.004, ЭПК, ЭПВ-АРС, силовая схема.

Каждая страница — один HTML-файл, открывается двойным щелчком (без сервера). Точка входа: `index.html` (или `Интерактивное пособие 81-717-714.html`).

`Материалы/` — картинки, миниатюры и исходники генераторов схем (`_исходники ...`).
